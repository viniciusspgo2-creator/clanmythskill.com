## Pesquisa de soluções no GitHub

Pesquisa realizada antes das animações: Motion (`motiondivision/motion`, MIT), AutoAnimate (`formkit/auto-animate`, MIT), Vanilla Tilt (`micku7zu/vanilla-tilt.js`, MIT). Os três repositórios tiveram licença verificada pela API do GitHub. Nenhum deles foi incorporado ou teve código copiado: os efeitos usados são pequenos módulos originais com CSS, IntersectionObserver, Pointer Events e requestAnimationFrame, para reduzir dependências e respeitar reduced-motion.
